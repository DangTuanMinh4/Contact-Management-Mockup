# Plan: Contact Manager

## Mục tiêu
Xây dựng ứng dụng quản lý danh bạ.

## Tính năng
1. CRUD danh sách liên hệ (tên, số điện thoại, email)
2. Tìm kiếm liên hệ
3. Phân trang cơ bản

## Công nghệ
- Frontend: React
- HTTP client: Axios
- Fake API: JSON Server
